# 机器学习学习日志

我用这个仓库记录自己从零学机器学习的过程：跑得通的代码、踩过的坑、复习用的笔记。

## 这是什么

不是又一份教程——网上教程已经够多了。这里只放我自己跑通过、并且卡住过的东西。

每个主题一个文件夹，里面固定两样：

1. 能直接跑的代码
2. 一段「我卡在哪、怎么绕出来的」

第 2 样才是这个仓库最值钱的部分。教程到处都有，踩坑记录没有。

## 适合谁看

- 跟我一样在自学，卡在「教程看得懂、自己写不出」那一步的人。
- 想要一份能直接抄过去改的模板的人。

## 怎么跑起来

```bash
git clone https://github.com/Chaoyang75/ml-learning.git
cd ml-learning
pip install -r requirements.txt
jupyter lab
```

打开 `notebooks/`，从编号 01 开始按顺序看。

## 目录

| 目录 | 放什么 |
| --- | --- |
| `notebooks/` | 按顺序编号的学习笔记，每个主题一个文件 |
| `src/` | 从 notebook 里沉淀出来的、能复用的函数 |
| `data/` | 本地数据。**不进版本库**，见 `.gitignore` |
